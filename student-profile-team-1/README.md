# Student Profile Team 1

A shared student profile repository built as part of the **Bosscoder School of Technology – Web Development Lab Worksheet** ("Build a Student Profile Repository Using Git and GitHub").

## Team Roles

| Student   | Responsibility         | Branch             | File           |
|-----------|------------------------|--------------------|----------------|
| Student 1 | Team Lead and Reviewer | `main`             | `README.md`    |
| Student 2 | Profile Developer      | `feature/profile`  | `profile.html` |
| Student 3 | Skills Developer       | `feature/skills`   | `skills.html`  |
| Student 4 | Contact Developer      | `feature/contact`  | `contact.html` |

## Project Files

- [`profile.html`](profile.html) – student profile page
- [`skills.html`](skills.html) – skills page
- [`contact.html`](contact.html) – contact page
- [`GIT_WORKFLOW.md`](GIT_WORKFLOW.md) – step-by-step Git commands for every worksheet step

## Workflow Used

1. Team lead creates the public repository and adds this README.
2. Every member clones the repository.
3. Each developer creates a feature branch and their own HTML file.
4. Each developer runs `git add`, `git commit` and `git push`.
5. Each developer raises a Pull Request into `main`.
6. The team lead reviews and merges the approved Pull Requests.
7. All HTML files are verified in `main`.

## How to View

Clone the repository and open any `.html` file in a browser.

```bash
git clone <repository-url>
```
